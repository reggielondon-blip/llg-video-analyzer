# HeyGen Brand Assets

Drop the firm logo files here so the script sheets and CSVs reference a version-controlled asset.

## Add these files
- **`logo-full.png`** — the full "L & L LAW GROUP PLLC" lockup (the cyan double-L mark + wordmark). Transparent background, ≥ 1500px wide. Used for the **large centered outro** in the v5 series.
- **`logo-mark.png`** — a tighter crop / icon version (the cyan double-L only, or the compact lockup) for the small **top-right watermark**. Transparent background, ≥ 600px wide.
- *(optional)* **`logo-full-white.png`** and **`logo-mark-white.png`** — white/knockout versions for placing over bright b-roll.

> The logo image shared in chat was not saved to this repo automatically. Export it from your brand kit and commit it here with the exact filenames above — nothing else needs to change.

## Placement spec (matches the v5 locked layout)

**Top-right watermark — every video, 100% of runtime**
- Corner: **top-right**, ~5% edge inset.
- Size: **~14–18% of frame width** (1080×1920 → roughly 150–195px wide).
- Opacity: **~70–80%**, soft drop shadow so it reads over any b-roll.
- Use `logo-mark.png` (or `-white` version over bright footage).
- The floating-head avatar never uses the top-right corner — it's reserved for this.

**Large centered outro — last 2.5–3.5s only**
- Position: **centered**.
- Size: **~55–65% of frame width**.
- Reveal: particle-assemble or light-bloom out of the final b-roll; the top-right watermark can crossfade into it.
- Use `logo-full.png` (or `-white` version).
- Place the shareable takeaway line above it and the compliance footer below it.
